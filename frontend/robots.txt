# ！这个文件刻意很短。要让某个页面【不被收录】，正确做法是让它发出
#   X-Robots-Tag: noindex 响应头（见 backend/main.py），而不是在这里 Disallow。
#
#   两者解决的是不同的问题：
#       Disallow = 别来抓
#       noindex  = 别收录
#   更要命的是它们会互相打架：被 Disallow 的路径爬虫根本抓不到，
#   也就永远看不到那个 noindex，于是当别的网站链过来时，
#   它仍然可能出现在结果页里（只是没有摘要文字）—— 而你已经以为挡住了。
#
#   所以本站的策略是：SPA 路由和后台一律【允许抓取】+ noindex。
# ============================================================================

User-agent: *
# /api/ 不是给人看的页面，抓了只是白花双方带宽。
# 接口本来就不参与收录，所以这里用 Disallow 不会引发上面说的那个矛盾。
Disallow: /api/

#   会去一个不存在的地址找站点地图，而且报告里只会说「读不到」。
#   （v0.32.2：已从 pccode.cn 换成 mcfr.cn。旧域名如果保留，仍会 301 过来。）
